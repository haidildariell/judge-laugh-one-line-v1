## Entry

> I joined a gym to get fit, but the treadmill filed a restraining order after I used it as a coat rack for six months.

(117 characters)

## Program

`main.py` is a small, deterministic Python 3 program with no network access
and no dependencies. It writes the one-liner above to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

## Why this line

The setup builds a familiar expectation (joining a gym to get fit), then
breaks it twice: the treadmill takes legal action, and the reason is that it
spent six months as a coat rack. Every word earns its place, the punchline
lands at the end, and the closing image — a treadmill draped in coats — is
concrete and easy to picture.
